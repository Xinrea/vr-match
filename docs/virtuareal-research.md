# VirtuaReal 人格测验资料与匹配维度

更新日期：2026-07-31

## 结论

第一版测验建议只覆盖 **VirtuaReal Project（本部）中仍在活动、资料足够且风格差异明显的成员**，暂不混入 VirtuaReal Link 与 VirtuaReal Star。

原因：VirtuaReal 官网的成员 API 目前仍以旧成员资料为主，缺少 2024—2026 年的多批新人，也没有可靠的活动状态字段。萌娘百科的 VirtuaReal 总条目已整理到 27 期，并标注了毕业或停止活动状态；B 站官方公告和个人主页可以进一步校验近期活动。因此资料优先级为：

1. VirtuaReal 官网与官方 B 站公告：身份、期数、账号、基础设定。
2. 成员 B 站主页与近期公开内容：直播类型、更新状态、内容偏好。
3. 萌娘百科：成员沿革、毕业状态、官方式简介与常见特色补充。
4. 主观归纳：只用于匹配评分，必须标为“推定”，不能作为事实陈述。

## 推荐的匹配维度

不要用 MBTI 字母直接硬套主播。更适合本项目的是“观众想看什么、想获得什么感受”。以下 8 个连续维度都采用 1–5 分：

| 维度 | 1 分 | 5 分 | 可转化的问题 |
| --- | --- | --- | --- |
| `energy` 场域能量 | 安静、低刺激 | 热闹、高刺激 | 下班后你想看安静陪伴还是热闹整活？ |
| `warmth` 情绪温度 | 冷感、克制 | 温柔、治愈 | 你希望主播像酷酷的同好，还是温暖的朋友？ |
| `chaos` 喜剧/混乱度 | 稳定、沉着 | 高密度梗与意外 | 你更喜欢舒适稳定，还是随时可能发生节目效果？ |
| `structure` 内容结构 | 随性杂谈 | 目标清晰、企划感强 | 你喜欢漫无目的聊天，还是有主题和进度的直播？ |
| `intimacy` 互动亲近度 | 舞台式欣赏 | 强陪伴、朋友感 | 你更想欣赏表演，还是参与弹幕互动？ |
| `roleplay` 世界观浓度 | 日常真实感 | 设定沉浸感 | 你在意主播的人设、世界观和角色扮演吗？ |
| `focus` 专注深度 | 内容跳跃、多样 | 长时间钻研一个主题 | 你喜欢多样切换，还是沉浸式长线内容？ |
| `novelty` 新奇探索度 | 熟悉舒适区 | 新游戏、新企划、新知识 | 你会为了新鲜感尝试陌生内容吗？ |

内容偏好不适合做单轴，应使用独立权重：

- `music`：歌回、翻唱、原创音乐、舞台表演。
- `gaming`：游戏实况、竞技、长流程、挑战。
- `chat`：杂谈、陪伴、生活分享、弹幕互动。
- `variety`：整活、联动、企划、反应类内容。
- `knowledge`：文化、推理、技术、观察或主题型内容。

## 评分与匹配建议

用户回答先计算 8 个风格维度与 5 个内容偏好，再与每位成员向量比较。推荐使用加权距离，而不是简单累计“某个选项对应某个人”。

```text
distance(member, user)
  = Σ styleWeight[i] × |member.style[i] - user.style[i]|
  + Σ contentWeight[j] × |member.content[j] - user.content[j]|
```

最终结果建议展示：

- 1 位最佳匹配。
- 2 位相邻匹配，避免把人格测验包装成唯一真相。
- 3 条“为什么适合你”，分别来自内容、氛围、互动方式。
- 1 条“你可能需要适应”，例如直播较长、游戏占比高或世界观浓度低。
- 成员主页链接与“资料更新时间”。

## 题目设计原则

- 12–16 题足够，完成时间控制在 2–3 分钟。
- 每题最多 4 个选项，不要让成员姓名出现在题目中。
- 一道题最多影响 2–3 个维度，防止单题权重过大。
- 内容偏好题约占 40%，观看氛围与互动偏好约占 60%。
- 加入 2 道情境题，例如“深夜打开直播时最想看到什么”。
- 不询问性别、年龄、星座等与观看偏好没有直接关系的个人信息。

## 数据质量规则

每位候选成员应保存以下字段：

```json
{
  "name": "莉蔻Liko",
  "branch": "VirtuaReal Project",
  "generation": 27,
  "status": "active",
  "bilibiliUid": "1536601294",
  "officialBio": "一只正在努力完成探索任务的小兔子",
  "styleScores": {},
  "contentScores": {},
  "evidence": [],
  "confidence": "high",
  "reviewedAt": "2026-07-31"
}
```

`evidence` 至少包含两个不同来源，其中一个必须是官方账号、本人主页或近期本人内容。社区百科只能作为补充来源。
